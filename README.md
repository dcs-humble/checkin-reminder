# 打卡自动提醒

Windows 桌面程序：读取腾讯文档打卡统计，核对 Excel 花名册，配置多班级、定时 QQ 提醒，并导出上周每天的未打卡名单。

## 安装与运行

1. 安装 Windows 版 Python 3.12（含 Tkinter、Python Launcher），安装 Microsoft Edge 和 QQ，并启用 Windows 中文 OCR 语言组件。
2. 双击 `setup.bat` 安装运行环境与依赖，再双击 `start.bat` 打开程序。
3. 设置班级名称、QQ 群关键词、自己的花名册（姓名、学号两列）和腾讯文档表单链接。首次使用需登录专用 Edge 中的腾讯文档。
4. 先进行自检和演练，核对名单与目标群，再启用定时提醒。

## 上周名单跨月修复

导出按上一个完整自然周（周一到周日）计算。日历根据完整年月日自动点击上一月或下一月，包括跨年；按完整日期匹配日期格，再核对统计标题中的月、日。日期不可选、标题缺失或名单计数异常会明确报错。
